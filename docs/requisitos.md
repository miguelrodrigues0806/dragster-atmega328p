# Requisitos para o projeto do Robô Dragster

Títulos: Usas cardinais. # Título 1 (H1), ## Título 2 (H2).

Ênfase: **este texto fica em negrito** e *este em itálico*.

Listas: Inicias a linha com um hífen - item da lista para bullets não ordenados.

Blocos de Código: Utilizas três crases (```) para delimitar excertos de código, o que é fundamental para documentares as rotinas de interrupção ou PWM do vosso ATmega328P.
